**Step 1 — DI refactor for tools_metadata.py:**

For each `_*_impl` function, add explicit parameters for the repositories/services it needs instead of calling `_get_book_repo()` etc. internally:

- `_list_available_books_impl(book_repo: BookRepository) -> str:` — receives book_repo as param
- `_get_book_info_impl(book_id: str, book_repo: BookRepository) -> str:` — receives book_repo as param
- `_update_book_metadata_impl(book_id: str, ..., book_repo: BookRepository) -> str:` — receives book_repo as param
- `_enrich_book_impl(book_id: str, ..., book_repo: BookRepository) -> str:` — receives book_repo as param

Update each corresponding `@mcp.tool` wrapper to call `_make_book_repo()` (a module-level factory, renamed from `_get_book_repo` to clarify it's a factory) and pass to the impl:
```python
@mcp.tool(annotations=...)
def list_available_books() -> str:
    """..."""
    return _list_available_books_impl(_make_book_repo())
```

The factory function `_make_book_repo()` keeps the lazy global `_db_connection` pattern — that is OK. The key requirement is that `_*_impl` functions do NOT call any factory/global accessor internally.

**Step 2 — DI refactor for tools_search.py:**

- `_search_books_impl(query, ..., search_service: SearchService) -> str:` — receives search_service
- `_get_book_structure_impl(book_id, ..., book_repo: BookRepository, chunk_repo: ChunkRepository) -> str:` — receives both repos
- `_get_book_chunks_impl(book_id, ..., chunk_repo: ChunkRepository) -> str:` — receives chunk_repo

Update `@mcp.tool` wrappers to call factories and pass results:
```python
@mcp.tool(annotations=...)
def search_books(...) -> str:
    """..."""
    return _search_books_impl(query, ..., search_service=_make_search_service())
```

Rename factory functions from `_get_*` to `_make_*` for clarity: `_make_search_service()`, `_make_book_repo()`, `_make_chunk_repo()`.

**Step 3 — DI refactor for tools_books.py:**

- `_remove_book_impl(book_id: str, book_repo: BookRepository, chunk_repo: ChunkRepository) -> str:` — receives repos
- `_reindex_all_books_impl(book_repo: BookRepository, ...) -> str:` — receives book_repo (and search_service if needed)

**EXCEPTION for `_add_book_impl`:** This function creates its own DB connection inside `asyncio.to_thread` for thread-safety. Do NOT inject a connection object. Instead, `_add_book_impl` may keep its internal `init_db(); conn = get_connection()` pattern. However, it should still accept a `validate_fn` or simply call `validate_epub_path` from the service layer. The key STRC-03 test is: `_add_book_impl` must NOT call `_get_book_repo()` or `_get_search_service()` — it can call `get_connection()` directly since it needs a thread-local connection.

Update `@mcp.tool` wrappers similarly.

**Step 2 — Update test_mcp.py for DI and new module structure:**

The tests in `tests/test_mcp.py` do two things that must change:

**A. Tests that set `tools._search_service = mock_service`:**
These tests (approximately 20+ occurrences) set the module-level global to inject a mock. After DI, the _impl functions accept the service as a parameter. Update these tests to pass the mock directly:

Before:
```python
from mnemo.mcp import tools
original_service = tools._search_service
tools._search_service = mock_service
try:
    result = tools._search_books_impl("query")
finally:
    tools._search_service = original_service
```

After:
```python
from mnemo.mcp.tools import _search_books_impl  # still works via re-export shim
result = _search_books_impl("query", search_service=mock_service)
```

This is MUCH cleaner — no save/restore global dance.

**B. Tests that set `tools._db_connection = temp_db["conn"]`:**
These tests inject a temp DB connection. After DI, _impl functions accept `book_repo` and `chunk_repo` as parameters. Update:

Before:
```python
from mnemo.mcp import tools
original_conn = tools._db_connection
tools._db_connection = temp_db["conn"]
try:
    result = tools._get_book_info_impl("abc123")
finally:
    tools._db_connection = original_conn
```

After:
```python
from mnemo.mcp.tools import _get_book_info_impl
from mnemo.storage import BookRepository
book_repo = BookRepository(temp_db["conn"])
result = _get_book_info_impl("abc123", book_repo=book_repo)
```

**C. Tests that import `from mnemo.mcp.tools import add_book` or `reindex_all_books`:**
These test the @mcp.tool decorated functions directly. They still need to patch the module-level globals because the MCP wrappers call factory functions. These tests should patch on the DOMAIN module (not tools.py shim):

Before:
```python

# ... tools._db_connection = ...
```

After:
```python
from mnemo.mcp.tools_books import add_book

tools_books_mod._db_connection = temp_db["conn"]
try:
    ...
finally:
    tools_books_mod._db_connection = original_conn
```

**D. Tests that access `tools._search_service` via `from mnemo.mcp import tools` and then patch + call `_search_books_impl` (which was on the same module):**
After DI, these become simpler — just pass the mock to the impl function parameter.

**IMPORTANT:** Work through EVERY test method in test_mcp.py systematically. The file is 2185 lines. There are approximately 60+ test methods. Each one that patches `tools._search_service` or `tools._db_connection` needs updating.

General pattern for converting tests:
1. If test calls `_*_impl(...)` — pass deps as keyword args, remove global patching
2. If test calls a `@mcp.tool` wrapper (e.g., `add_book(...)`) — must still patch on domain module (wrapper calls factory)
3. If test imports `from mnemo.mcp.tools import _something` — keep as-is (re-export shim handles it)
4. If test does `from mnemo.mcp import tools; tools._db_connection = ...` — for _impl calls, switch to direct DI; for wrapper calls, patch on `tools_books` or `tools_search` or `tools_metadata` as appropriate
