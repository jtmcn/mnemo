**Implementation function `_update_book_metadata_impl()`:**

Place it after `_get_book_info_impl()` and before `_format_search_results()`, following the existing pattern.

```python
def _update_book_metadata_impl(
    book_id: str,
    title: str | None = None,
    authors: list[str] | None = None,
    isbn: str | None = None,
) -> str:
```

**Logic:**
1. Log the call: `logger.info(f"update_book_metadata: book_id={book_id}, title={title!r}, authors={authors!r}, isbn={isbn!r}")`
2. Validate `book_id`: if not book_id or `len(book_id) != 6`, return `"Error: book_id must be a 6-character identifier"`
3. Validate at least one field: if all three are None, return `"Error: At least one of title, authors, or isbn must be provided"`
4. Validate title not empty: if `title is not None and not title.strip()`, return `"Error: title cannot be empty"`
5. Normalize empty isbn: if `isbn is not None and isbn.strip() == ""`, set `isbn = None` (treats empty string as "clear ISBN")
6. In try/except block:
   - Get `book_repo = _get_book_repo()`
   - Call `updated = book_repo.update(book_id=book_id, title=title, authors=authors, isbn=isbn)`
   - If `updated is None`, return `f"Book not found: {book_id}"`
   - Invalidate search cache: `global _search_service` then `if _search_service is not None: _search_service._book_cache.clear()`
   - Return `_get_book_info_impl(book_id)` to reuse the existing formatted output
7. Catch Exception: `logger.exception("update_book_metadata failed")` and `return f"Error: {e}"`

**Tool registration:**

Place after the existing `get_book_info` tool registration at the end of the file:

```python
@mcp.tool
def update_book_metadata(
    book_id: str,
    title: str | None = None,
    authors: list[str] | None = None,
    isbn: str | None = None,
) -> str:
    """Update a book's metadata (title, authors, or ISBN).

    Changes are saved to the database and immediately reflected in
    search results and book info lookups.

    Args:
        book_id: 6-character book identifier (from list_available_books)
        title: New title for the book
        authors: New list of author names (replaces existing authors)
        isbn: New ISBN for the book (empty string clears ISBN)

    Returns:
        Updated book details, or error message
    """
    return _update_book_metadata_impl(book_id, title, authors, isbn)
```
