Implementation for `_remove_book_impl`:

1. **Validate book_id:** If empty or not 6 chars, return `"Error: book_id must be a 6-character identifier"` (same pattern as `_get_book_info_impl`).

2. **Fetch book info BEFORE deletion** (for the response message). Use `_get_book_repo()` to get the book. If not found, return `f"Error: Book not found: {book_id}"`.

3. **Get chunk count** before deletion using `ChunkRepository(_db_connection).count_by_book(book_id)`.

4. **Perform deletion** by calling `ingest.remove_book(book_id)` from `mnemo.ingest`. Import it locally inside the function as `from mnemo.ingest import remove_book as pipeline_remove` to avoid name collision with the MCP tool function. Call `pipeline_remove(book_id)`.

5. **Invalidate search cache** using the Phase 5 pattern:
   ```python
   global _search_service
   if _search_service is not None:
       _search_service._book_cache.clear()
   ```

6. **Return success message** with deleted book info:
   ```python
   authors_str = ", ".join(book.authors) if book.authors else "Unknown"
   return f"Removed: {book.title} by {authors_str} (ID: `{book.id}`) - {chunk_count} chunks deleted"
   ```

7. **Wrap in try/except** for unexpected errors, return `f"Error: {e}"` (same pattern as other tools).

The `@mcp.tool remove_book` decorated function is a thin sync wrapper (no async needed -- removal is fast):
```python
@mcp.tool
def remove_book(book_id: str) -> str:
    """Remove a book from your library.

    Permanently deletes the book, all its chunks, and search vectors.
    The original EPUB file on disk is not affected.

    Args:
        book_id: 6-character book identifier (from list_available_books)

    Returns:
        Confirmation with deleted book details, or error message
    """
    return _remove_book_impl(book_id)
```

Important details:
- Do NOT make this async. Removal via `ingest.remove_book()` is fast (no API calls).
- `ingest.remove_book()` manages its own DB connection internally. Do NOT pass `_db_connection` to it.
- The EPUB file on disk is intentionally NOT deleted (CONTEXT.md decision).
- Log the operation at the start with `logger.info(f"remove_book: book_id={book_id}")`.
