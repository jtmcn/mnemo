    1. `_safe_extract(tar: tarfile.TarFile, dest: Path) -> None`

       - Raise ValueError on traversal attempt

    2. `backup_sqlite(source_path: Path, dest_path: Path) -> None`
       - Use sqlite3.connect(source_path) and sqlite3.connect(dest_path)
       - Call source.backup(dest) to produce WAL-consolidated copy
       - Close both connections in finally block

    3. `export_chromadb(client: chromadb.ClientAPI, dest_path: Path, collection_name: str = "mnemo", batch_size: int = 5000) -> int`
       - Get collection via client.get_collection(collection_name)
       - Paginate with collection.get(include=["embeddings","metadatas","documents"], limit=batch_size, offset=offset)
       - Convert embeddings to list via .tolist() if numpy array (check with hasattr or isinstance)
       - Write JSON with all_data dict: {"ids": [...], "embeddings": [...], "metadatas": [...], "documents": [...]}
       - Return total vector count

    4. `create_backup(db_path: Path, chroma_client: chromadb.ClientAPI, output_path: Path, collection_name: str = "mnemo") -> dict`
       - Use tempfile.TemporaryDirectory() for staging
       - Call backup_sqlite() for SQLite
       - Call export_chromadb() for vectors
       - Build manifest.json with:
         - mnemo_version: from mnemo.__version__
         - schema_version: read from DB's schema_version table (per DATA-01)
         - chromadb_version: from chromadb.__version__
         - created_at: ISO format UTC timestamp
         - book_count: SELECT COUNT(*) FROM books
         - chunk_count: SELECT COUNT(*) FROM chunks
         - vector_count: from export_chromadb return value
       - Create tar.gz with tarfile.open(output_path, "w:gz")
       - Add manifest.json, mnemo.db, chroma_export.json to archive
       - Return manifest dict

    5. `_restore_chromadb(client: chromadb.ClientAPI, export_path: Path, collection_name: str = "mnemo", batch_size: int = 5000) -> int`
       - Read JSON from export_path
       - Delete existing collection if present (client.delete_collection)
       - Create new collection with metadata={"hnsw:space": "cosine"} (per Pitfall 3 from research)
       - Add vectors in batches (batch_size at a time) via collection.add()
       - Return vector count

    6. `restore_backup(archive_path: Path, db_path: Path, chroma_client: chromadb.ClientAPI, force: bool = False, collection_name: str = "mnemo") -> dict`
       - Check if db_path exists; if so, require force=True or raise FileExistsError
       - Extract to tempfile.TemporaryDirectory() using _safe_extract()
       - Validate manifest.json exists (raise ValueError if missing)
       - Parse manifest, check schema_version <= LATEST_VERSION (raise ValueError if future)
       - Call backup_sqlite(tmp/mnemo.db, db_path) to restore SQLite
       - Call _restore_chromadb() to restore vectors
       - Return manifest dict
