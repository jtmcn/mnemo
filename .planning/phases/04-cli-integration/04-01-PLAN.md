<task type="auto">
  <name>Task 1: Create CLI module with add, list, and remove commands</name>
  <files>src/mnemo/cli.py, pyproject.toml</files>
  <action>
Create src/mnemo/cli.py with Typer app and Rich console:

1. **App setup:**
   - Create Typer app with `no_args_is_help=True`, `pretty_exceptions_show_locals=False`
   - Create Rich Console instance at module level
   - Define `main()` function that calls `app()`

2. **`add` command (CLI-01):**
   - Arguments: `paths: list[Path]` (positional, accepts multiple EPUBs)
   - Options: `--verbose/-v`, `--json`, `--force/-f` (skip duplicate prompt)
   - Implementation:
     - For each path: validate exists, check for duplicate via file hash
     - If duplicate found and not `--force`: use `typer.confirm()` (but check `console.is_terminal` first - if non-TTY, print error and exit 1)
     - Show Rich Progress spinner with stages: "Parsing...", "Indexing..." (ingest_book is atomic, can't show granular stages)
     - Call `ingest_book(path, embed=True, force=force_flag)`
     - On success: print "Added: {title} by {authors} ({id}) - {chunks} chunks"
     - On error: print error message with path context, exit 1 (fail fast)
   - JSON mode: output list of `{"id", "title", "authors", "chunks"}` objects
   - Disable progress spinner when `--json` (use `disable=json_output`)

3. **`list` command (CLI-03):**
   - Options: `--json`
   - Implementation:
     - Call `init_db()`, `get_connection()`, `BookRepository(conn).list_all()`
     - If empty: print "No books indexed" (or empty JSON array)
   - Rich output: Table with columns ID (cyan), Title (green), Authors
   - JSON output: array of `{"id", "title", "authors"}` objects

4. **`remove` command (CLI-02):**
   - Arguments: `book_id: str`
   - Options: `--json`
   - Implementation:
     - Call `remove_book(book_id)`
     - If returned True: print "Removed: {book_id}"
     - If returned False: print warning "Book not found (already removed?)", exit 0 (per CONTEXT.md)
   - JSON output: `{"removed": true/false, "book_id": "..."}`

5. **Verify pyproject.toml already has entry point:**
   - Should already have `mnemo = "mnemo.cli:main"` in `[project.scripts]`
   - Add `typer>=0.12` to dependencies if not present

Error handling patterns:
- Missing file: `console.print(f"[red]File not found: {path}[/red]")`, `raise typer.Exit(1)`
- API/embedding failure: catch exception, print error with context, delete partial work (ingest_book handles this), `raise typer.Exit(1)`
- Duplicate without --force in non-TTY: print error "Book exists. Use --force to re-index.", `raise typer.Exit(1)`
  </action>

Add remaining commands to cli.py:

1. **`search` command (CLI-04):**
   - Arguments: `query: str` (positional)
   - Options:
     - `--limit/-n`: int, default 5, help "Max results"
     - `--book/-b`: str | None, help "Filter by book ID"
     - `--json`: bool
   - Implementation:
     - Create `SearchService()`, call `service.search(query, top_k=limit, book_id=book)`
     - Handle empty results: "No results found"
   - Rich output (per CONTEXT.md):
     - For each result: `[bold]{book_title}[/bold] > {section_path}`
     - Then content (plain text, no truncation - show full chunk)
     - Empty line between results
   - JSON output: array of `{"book_id", "book_title", "section_path", "content", "score"}`
   - Attribution format: " > ".join(section_path) if section_path else "No section"

2. **`serve` command (CLI-05):**
   - No arguments or options
   - Implementation:
     - Import from mnemo.mcp: `from mnemo.mcp.server import mcp` and `import mnemo.mcp.tools`
     - Call `mcp.run()` which blocks and handles STDIO
   - CRITICAL: No print() or console.print() in this command - MCP uses STDIO for JSON-RPC
   - Just the mcp.run() call, nothing else
  </action>
