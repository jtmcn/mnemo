  <files>src/mnemo/mcp/server.py</files>
  <read_first>src/mnemo/mcp/server.py</read_first>
  <action>
Edit `src/mnemo/mcp/server.py` to read the log level from the `MNEMO_LOG_LEVEL` environment variable.

1. Add `import os` to the imports (after `import sys`, line 8).

2. Replace the `logging.basicConfig(...)` block (lines 15-19) with:

```python
# Configure logging to stderr (critical for STDIO)
_level_name = os.environ.get("MNEMO_LOG_LEVEL", "INFO").upper()
_log_level = getattr(logging, _level_name, logging.INFO)
logging.basicConfig(
    level=_log_level,
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    handlers=[logging.StreamHandler(sys.stderr)],
)
```

This uses the standard Python pattern: `getattr(logging, "DEBUG")` returns `10` (the int constant). If an invalid level name is given, it falls back to `logging.INFO`. No third-party library needed.

Do NOT change the log format string or the stderr handler — those are required for STDIO transport.
Do NOT use `logging.getLevelName()` — it is deprecated.

Per CONF-03: All module-level `getLogger(__name__)` calls throughout mnemo inherit from this root config, so this single change affects all logging output.
