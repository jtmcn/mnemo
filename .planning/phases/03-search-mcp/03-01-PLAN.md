Create SearchService that coordinates both search backends:

```python
class SearchService:
    """Coordinates FTS5 and ChromaDB search with RRF fusion."""

    def __init__(
        self,
        db_path: Path | None = None,
        chroma_path: Path | None = None,
    ):
        """Initialize with paths (defaults to ~/.mnemo/)."""
        # Lazy initialization - don't connect until first search

    def search(
        self,
        query: str,
        top_k: int = 10,
        book_id: str | None = None,
        content_type: str | None = None,
        mode: Literal["hybrid", "semantic", "keyword"] = "hybrid",
    ) -> list[SearchResult]:
        """Search with optional filters and mode selection."""
```

Implementation details:

1. **Lazy initialization:**
   - Don't create DB/ChromaDB connections in __init__
   - Initialize on first search (avoids import-time side effects)
   - Store config only in __init__

2. **Keyword search path:**
   - Use ChunkRepository.search_fts(query, book_id, content_type, limit=top_k*2)
   - Request 2x results for better RRF fusion

3. **Semantic search path:**
   - Lazy import DatabricksEmbedder (avoid credential requirement at import)
   - Generate query embedding: `embedder.embed([query])[0]`
   - Use VectorStore.query(embedding, n_results=top_k*2, book_id, content_type)

4. **RRF fusion (hybrid mode):**
   - Get chunk_ids from both result lists (preserving rank order)
   - Call reciprocal_rank_fusion([keyword_ids, semantic_ids])
   - Sort by RRF score descending
   - Take top_k results

5. **Attribution loading:**
   - For each result chunk_id, load book title from BookRepository
   - Cache book lookups to avoid repeated queries
   - Build SearchResult with full section_path from chunk

6. **Mode handling:**
   - "hybrid": Both searches + RRF fusion (default)
   - "semantic": Only vector search
   - "keyword": Only FTS5 search
   - If semantic search fails (no embeddings), fall back to keyword-only with warning

7. **Error handling:**
   - Empty query returns empty list
   - Missing book_id filter: search all books
   - Invalid content_type: search all types (or validate and raise?)
