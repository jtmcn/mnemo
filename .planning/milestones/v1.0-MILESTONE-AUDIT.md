## E2E User Flows

### Flow 1: Add Book
**Status:** COMPLETE
```
mnemo add book.epub
  -> CLI
  -> ingest_book()
  -> EPUBParser.parse()
  -> Chunker.chunk()
  -> BookRepository.add() + ChunkRepository.add_many()
  -> embed_book()
  -> DatabricksEmbedder.embed_batch()
  -> VectorStore.add()
```

### Flow 2: Search
**Status:** COMPLETE
```
mnemo search "query"
  -> CLI
  -> SearchService.search()
  -> ChunkRepository.search_fts() + VectorStore.query() + DatabricksEmbedder.embed_one()
  -> reciprocal_rank_fusion()
  -> SearchResult[]
```

### Flow 3: MCP Serve
**Status:** COMPLETE
```
mnemo serve
  -> CLI
  -> mcp.run()
  -> FastMCP server
  -> Claude Desktop calls search_books
  -> SearchService.search()
  -> formatted markdown results
```

### Flow 4: Remove Book
**Status:** COMPLETE
```
mnemo remove <id>
  -> CLI
  -> remove_book()
  -> BookRepository.delete() (CASCADE to chunks)
  -> VectorStore.delete_by_book()
```
