# Milestone v1.0: MVP

**Status:** SHIPPED 2026-02-10
**Phases:** 1-4
**Total Plans:** 11

## Overview

Personal technical book library with MCP search. Parse technical EPUBs preserving code blocks and structure, generate embeddings via Databricks GTE-large-en, and expose semantic search through an MCP server for Claude Desktop and Claude Code.

## Phases

### Phase 1: Foundation

**Goal**: System can parse technical EPUBs, chunk content intelligently, and store structured data with full text for later retrieval.
**Depends on**: None
**Plans**: 5 plans

Plans:
- [x] 01-01: Project setup — Python package structure and core data models
- [x] 01-02: EPUB parser — EPUB parsing with metadata, TOC, and content type detection
- [x] 01-03: SQLite storage — SQLite storage with FTS5 and cascade deletes
- [x] 01-04: Chunker — Smart chunking with code block preservation
- [x] 01-05: Integration — End-to-end pipeline and verification

**Details:**
- Pydantic models (Book, Chunk, ContentType) with 6-char hex IDs
- Publisher-specific CSS class detection (O'Reilly, Pragmatic, Manning)
- FTS5 auto-sync triggers, cascade deletes
- tiktoken-based chunker with atomic code/diagram/math/table units
- ingest_book() + remove_book() functions with duplicate detection

**Requirements:** EPUB-01 through EPUB-05, CHUNK-01 through CHUNK-04, STORE-02 through STORE-04 (12 total)
**Completed:** 2026-01-20

**Depends on**: Phase 1 (needs chunks to embed)
**Plans**: 3 plans

Plans:

- [x] 02-02: ChromaDB vector store — ChromaDB vector store with L2 normalization

## Milestone Summary

**Key Decisions:**
- GTE-large-en over BGE (BGE deprecated Feb 2026, GTE has 8192 token context)
- Code-aware chunking in Phase 1 (cannot be retrofitted)
- Dual storage: ChromaDB for vectors + SQLite for metadata/FTS
- 6-char hex book ID from SHA256
- L2 normalization for GTE unnormalized vectors
- RRF k=60 for hybrid search fusion
- Lazy imports throughout to avoid credential requirements at import time
- print() for JSON output to avoid Rich formatting interference

**Issues Resolved:**
- Publisher-specific EPUB code block detection (CSS class approach)
- ChromaDB metadata filtering with proper where clauses
- FTS5 special character handling via quote-wrapping
- MCP module execution via __main__.py entry point
- Claude Desktop PATH limitations (full Python path in config)

**Issues Deferred:**
- Code chunking heuristics need tuning with real data
- Similarity score thresholds need empirical calibration

**Technical Debt Incurred:**
- typer not in explicit pyproject.toml dependencies (works via chromadb transitive dep)
