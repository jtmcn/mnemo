```python
def create_epub_with_front_matter(
    front_matter_items: list[dict[str, str]],
    output_path: Path | None = None,
) -> Path:
```

Each `front_matter_items` dict has `filename` (e.g., "cover.xhtml") and `content` (HTML body). The function:
1. Creates a book with one normal chapter (in TOC and spine)
