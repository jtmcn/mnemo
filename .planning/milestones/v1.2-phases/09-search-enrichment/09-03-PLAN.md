  <name>Task 1: Add context expansion with section boundaries to SearchService</name>
  <files>src/mnemo/search/service.py, tests/test_search.py</files>
  <behavior>
    - _expand_result_context(result, window=1) fetches chunk at result.chunk_id, then neighbors via get_chunk_range(book_id, seq-window, seq+window)
    - Expansion stops when neighbor has different section_path than matched chunk
    - Returns dict with matched_chunk_id, book_id, start_seq, end_seq, chunks list
    - _deduplicate_expanded_results merges overlapping windows: if two expanded results overlap in (book_id, sequence range), combine into one block preserving both matched_chunk_ids
    - search() with context_window=0 returns list[SearchResult] (unchanged behavior)
    - search() with context_window>=1 returns list[dict] where each dict has: original SearchResult fields + context_chunks list + matched_chunk_ids set
  </behavior>
  <action>
1. Write tests in `tests/test_search.py`:
   - `test_context_window_zero_unchanged` -- search with context_window=0, verify returns identical to current behavior (list of SearchResult)
   - `test_context_window_expands_neighbors` -- set up chunks seq 0-4 same section, search returns chunk seq=2, context_window=1 should include seq 1,2,3
   - `test_context_window_stops_at_section_boundary` -- chunks seq 0-4 where seq 0-2 are section A and seq 3-4 are section B. Match on seq=2, window=2: should only get seq 0,1,2 (not 3,4)
   - `test_context_window_dedup_overlapping` -- two search results at seq=3 and seq=5 with window=2. Their windows overlap at seq=5. Should merge into single block seq 1-7 with both marked as matches
   - `test_context_window_preserves_match_markers` -- after dedup, matched_chunk_ids contains the original match IDs

   These tests should set up a test SQLite DB with chunks, mock the embedding/vector search, and call SearchService.search() directly.

2. Run tests (expect RED).

3. Implement in `SearchService` (service.py):

   a. Add `_expand_result_context(self, result: SearchResult, window: int) -> dict`:
      - Get matched chunk via self._chunk_repo.get(result.chunk_id)
      - If chunk is None, return dict with empty chunks
      - Fetch candidates via self._chunk_repo.get_chunk_range(chunk.book_id, chunk.sequence - window, chunk.sequence + window)
      - Filter to same section_path as matched chunk:
        - Walk from matched chunk backwards: include only if section_path matches, stop on first mismatch
        - Walk forwards same way
        - Result is contiguous same-section window
      - Return: {"matched_chunk_id": result.chunk_id, "book_id": chunk.book_id, "start_seq": ..., "end_seq": ..., "chunks": [...], "result": result}

   b. Add `_deduplicate_expanded_results(self, expanded: list[dict]) -> list[dict]`:
      - Group by book_id
      - Within each book, sort by start_seq
      - Merge overlapping ranges: if current.start_seq <= prev.end_seq + 1, merge
      - When merging, union the matched_chunk_ids and combine chunks (deduplicate by chunk.id)
      - Carry forward the SearchResult with highest score as the primary result
      - Return merged list

   c. Add `context_window: int = 0` parameter to `search()`:
      - After getting results from mode-specific method (and after section filtering from Plan 02), if context_window == 0, return results as-is (backward compatible)
      - If context_window >= 1:
        - Expand each result: expanded = [self._expand_result_context(r, context_window) for r in results]
        - Deduplicate: merged = self._deduplicate_expanded_results(expanded)
        - Return merged list (type changes to list[dict] when context_window > 0)

4. Run tests (expect GREEN).
